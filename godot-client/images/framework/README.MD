# 卡片卡面模板化说明


卡面渲染时不同资源和位置说明


资源:
- 加载框架 
	- 人物卡：res://images/framework/frame-c.png
	- 策略卡：res://images/framework/frame-s.png
	- 物品卡：res://images/framework/frame-i.png
- 费用图片：res://images/framework/costs/{费用值}.svg 
- 神性标识：res://images/framework/attribute/god.png
- 理性标识：res://images/framework/attribute/lx.png
- 灵性标识：res://images/framework/attribute/ling.png

区域位置和说明

|区域|横坐标|纵坐标|宽|高|对齐方式|显示方式|层级（越高越靠上）|条件|
|---|----|-----|--|--|------|--------|---------------|----|
|卡片框架|0|0|1500|2100|左对齐|png，原图片透明的地方透明显示|1|不同的卡类型加载不同的框架|
|标题区域|125|90|1250|80|左对齐|文本文字。白色字体 80px |2|所有种类的卡片都显示|
|属性区域|125|90|1250|80|右侧对齐|高度80px: 费用图片+属性图片（两个图片中间一小段间隔）|2|根据不同的费用和属性（神性或者理性）来显示不同的图片|
|范畴区域|125|1887|1250|70|居中|文本文字，白色 60px |2|显示每个卡的范畴（中文）|
|字段和效果区域|160|1300|1180|500|第一排居中，效果部分左对齐|文本文字。白色。第一行卡片字段用"|"分割居中显示，之后是一行的横线分割福以上是60px。之后是效果。多个开头要用圆圈标识。默认字体大小是60px.有排版算法，当字数超过高度时，字体缩小以显示全部内容。|2| 存在相应自动就显示|
|特殊属性区域|115|1885|165|70|左对齐|文本文字，白色，60px。如果是攻击力在结尾加上ACK|2|显示每个卡片特殊独有的部分。如人物卡的攻击力。策略卡的策略类型：普通，诡计，瞬时。物品卡的：普通，存留|
|卡片编号区|110|2010|640|80|左对齐|文本文字，白色，32px|2|显示卡片的编号|
|卡图|0|0|1500|2100|左对齐|png：如果存在取res://images/cards/{卡片编号}.png的图片|0|资源存在就显示|


以上坐标的0点都是左上角。坐标指向右下角。
