# 游戏场地布局设计文档

## 参考图片分析

布局分为三个主要区域：
1. **上方 - 对手区域**（镜像视角）
2. **中间 - 信息分割条**
3. **下方 - 自己区域**

---

## 布局详细说明

### 一、整体结构（从上到下）

```
+------------------ 屏幕顶部 ------------------+
| 菜单按钮  |    对手手卡区域    |   对手状态   |
+-----------+--------------------+-------------+
|           |  后 后 后 后 后    |   卡组      |
| 对手费用区 |  前 前 前 前 前    |   墓地      |
|  (竖直)    |                    |             |
+-----------+--------------------+-------------+
|======== 回合信息条: 回合数 | 当前玩家 | 阶段 ========|
+-----------+--------------------+-------------+
|           |  前 前 前 前 前    |   卡组      |
| 自己费用区 |  后 后 后 后 后    |   墓地      |
|  (竖直)    |                    |             |
+-----------+--------------------+-------------+
|  空位即可  |             自己手卡         |   自己状态   |
+------------------ 屏幕底部 ------------------+
```

---

### 二、各区域详细规格

#### 1. 菜单按钮 (MenuButton)
- **位置**: 左上角
- **尺寸**: 约 100x40 px
- **功能**: 打开游戏菜单（投降、退出等）

#### 2. 对手手卡区域 (OpponentHand)
- **位置**: 顶部中央
- **尺寸**: 横向长条，约占屏幕宽度的 60%
- **显示**: 卡背（不显示具体卡牌内容）
- **复用模块**: `addons/card-framework/hand.tscn` 或自定义

#### 3. 对手状态 (OpponentStatus)
- **位置**: 右上角
- **显示内容**:
  - HP: X
  - RP: X (Real Point)
- **尺寸**: 约 120x80 px

#### 4. 对手费用区 (OpponentCostZone)
- **位置**: 对手区域左侧
- **方向**: 竖直排列
- **复用模块**: `cost_zone.tscn`（需要调整方向为竖直）

#### 5. 对手战场 (OpponentBattleField)
- **位置**: 对手区域中央
- **布局**: 2行 x 5列 的格子
  - 第一行（上方）: 5个后场格子
  - 第二行（下方）: 5个前场格子
- **复用模块**: `battle_field_slot.tscn` x 10

#### 6. 对手卡组/墓地 (OpponentStacks)
- **位置**: 对手区域右侧
- **布局**: 竖直排列
  - 上方: 卡组（卡背朝上）
  - 下方: 墓地（卡面朝上）
- **复用模块**: `card_stack.tscn` x 2

#### 7. 信息分割条 (InfoBar)
- **位置**: 屏幕正中央（水平分割条）
- **显示内容**:
  - 回合数: X
  - 当前玩家: 自己/对手
  - 当前阶段: 回合开始/抽卡/复苏/主要1/战斗/主要2/回合结束
- **尺寸**: 全宽，约 40-50 px 高度

#### 8. 自己战场 (PlayerBattleField)
- **位置**: 自己区域中央
- **布局**: 2行 x 5列 的格子
  - 第一行（上方）: 5个前场格子
  - 第二行（下方）: 5个后场格子
- **注意**: 与对手的战场相比，前后场顺序相同（都是上前后下后）
- **复用模块**: `battle_field_slot.tscn` x 10

#### 9. 自己费用区 (PlayerCostZone)
- **位置**: 自己区域左侧
- **方向**: 竖直排列
- **复用模块**: `cost_zone.tscn`（需要调整方向为竖直）

#### 10. 自己卡组/墓地 (PlayerStacks)
- **位置**: 自己区域右侧
- **布局**: 竖直排列
  - 上方: 卡组（卡背朝上）
  - 下方: 墓地（卡面朝上）
- **复用模块**: `card_stack.tscn` x 2

#### 11. 自己手卡区域 (PlayerHand)
- **位置**: 底部中央
- **尺寸**: 横向长条，约占屏幕宽度的 60%
- **显示**: 卡面朝上（显示具体卡牌内容）
- **复用模块**: `addons/card-framework/hand.tscn`

#### 12. 自己状态 (PlayerStatus)
- **位置**: 右下角
- **显示内容**:
  - HP: X
  - RP: X
- **尺寸**: 约 120x80 px

### 三、需要复用的场景模块

| 模块名 | 路径 | 用途 | 需要修改 |
|--------|------|------|----------|
| battle_field_slot | `battle_field_slot.tscn` | 战场格子（前/后场） | 添加淡蓝/淡橙背景色 |
| card_stack | `card_stack.tscn` | 卡组/墓地堆叠 | 支持卡背显示、竖直布局 |
| cost_zone | `cost_zone.tscn` | 费用区 | 支持竖直布局 |
| Hand | `addons/card-framework/hand.tscn` | 手卡区域 | 直接使用 |
| CardDisplay | `card_display.tscn` | 卡牌显示 | 用于预览 |

### 四、当前实现的问题

对比现有 `game_board.tscn` 和图片布局，主要差异：

1. **当前**: 费用区在右侧（状态栏左侧）
   **应该**: 费用区在左侧（竖直排列）

2. **当前**: 卡组和墓地在战场左侧
   **应该**: 卡组和墓地在战场右侧

3. **当前**: 手卡区域没有明确的横向长条区域
   **应该**: 手卡是横向长条区域

4. **当前**: 对手区域和自己区域结构不一致
   **应该**: 都是战场居中，费用区左，卡组右

5. **当前**: 缺少中央信息分割条
   **应该**: 有显示回合信息的分割条
